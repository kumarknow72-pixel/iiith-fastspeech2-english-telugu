## Language entry points (working branch)

The repository now includes the requested path layout:

- `English/preprocess.py`, `English/train.py`, `English/inference.py`, `English/config.yaml`
- `Telugu/preprocess.py`, `Telugu/train.py`, `Telugu/inference.py`, `Telugu/config.yaml`

**Important implementation limitation:** these six Python files are thin stage launchers around the existing `fs2_pipeline_colab.py`. The current model uses a shared English+Telugu vocabulary and its pipeline loops over both languages. Therefore, invoking either language's launcher runs the paired pipeline for both languages; these are not independent per-language training implementations. The entry points are provided for discoverability and reproducibility, not as a claim that the pipeline has been fully refactored into isolated language modules.

Run from a Colab environment with the expected Google Drive project structure and dependencies available. Preprocessing uses cached alignments/metadata and writes features under `module4_final`; training can take substantial time and resumes from checkpoints; inference loads the saved checkpoints and runs the pipeline's built-in validation/custom synthesis. The assignment-specific E1–E4 and T1–T4 audio files were verified in the shared Drive Results folders, not generated by these thin launchers.

The existing pipeline supports environment switches `FS2_RUN_FEATURES`, `FS2_RUN_TRAIN`, and `FS2_RUN_SYNTH` (values `1` or `0`). The launchers set these automatically. **Do not run the training launchers unless you intentionally want to resume training.**
